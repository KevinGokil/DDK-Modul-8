Tentang Saya

Latar Belakang & Sekolah

Saya adalah siswa di SMK Negeri 4 Malang dan mengambil jurusan Rekayasa Perangkat Lunak (RPL). Saya memilih jurusan ini karena ingin tahu bagaimana sebuah aplikasi dan website dibuat dari awal.

Di sekolah, saya aktif mengikuti kegiatan praktikum Dasar-Dasar Kejuruan (DDK) mulai dari algoritma pemrograman dasar hingga perancangan tampilan web.

Minat & Tujuan Karier

Minat terbesar saya saat ini adalah di bidang Web Development, khususnya merancang tampilan halaman web yang rapi dan responsif agar nyaman dibuka di HP maupun laptop.

Setelah lulus SMK nanti, saya bercita-cita untuk bekerja sebagai Web Developer atau melanjutkan kuliah di jurusan Teknik Informatika.

Kompetensi & Keahlian

Mata pelajaran kejuruan dan software yang sedang saya pelajari di jurusan RPL:

Pemrograman Web Dasar

  • HTML5: Membuat struktur halaman, tabel, form, dan elemen semantik.
  • CSS3: Mengatur warna, teks, layout kolom, dan Responsive Web Design.
  • Algoritma Dasar: Memahami logika percabangan dan perulangan dasar.

Software & Tools

  • Visual Studio Code: Text editor utama untuk menulis kode HTML dan CSS.
  • XAMPP: Menjalankan web server lokal (Apache) di komputer.
  • Google Chrome: Menguji tampilan website dengan fitur Inspect / Developer Tools.

Materi Kejuruan (DDK)

  • Instalasi dan konfigurasi server lokal (localhost).
  • Penyusunan tata letak dengan sistem grid/kolom CSS.
  • Penerapan Media Queries untuk tampilan mobile dan desktop.
